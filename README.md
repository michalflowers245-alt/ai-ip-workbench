# 自媒体四员工工作台

这是一个只在本机运行的自媒体工作台，包含四名正式员工、共享知识库、发布数据回流、本机 OpenAI-compatible 代理，以及“小红书内容研究”模块。小红书模块会在用户亲自登录的专用 Chrome 中搜索关键词，收集原帖链接并逐条提取可见内容。

## 安装与启动

需要 Node.js 22 或更新版本，以及已安装的 Google Chrome。首次放到一台新电脑后，在项目目录运行：

```bash
npm ci
npm start
```

打开终端显示的本机网址。默认优先使用 `http://127.0.0.1:5177`；如果端口已占用且没有手动设置 `PORT`，服务会改用一个空闲端口。服务只绑定本机回环地址，不会直接暴露到局域网或公网。

macOS 可以双击项目内的 `启动自媒体工作台.command`。启动日志写到 `data/workbench.log`。

仓库附带四份通用员工策略和 Skill 白名单，个人工作区可用项目根目录下同名策略覆盖。工作台只在本机加载已安装的 Skill 文件，不随仓库分发第三方 Skill 内容。


此代码仓库从空工作区启动。剪辑、平台上传和指标回收可分别接入本机工具及账户授权。界面中的功能检测会显示当前可用项。

## 日常使用

- 文案、研究笔记、剪辑参数、发布目标等未保存输入会暂存于当前浏览器。切换工作台或刷新后可恢复；它们只有点击保存或交接后才成为工作台正式版本。人工审阅及发布授权勾选不会自动恢复。
- 如果其他窗口更新了同一任务，先“重新读取，保留草稿”，再对照新版本恢复或放弃自己的未保存内容。旧草稿不会直接覆盖新生成的稿件。清除浏览器数据会删除浏览器草稿；正式任务仍保存在项目文件中。
- 任务列表支持标题或 CONTENT-ID 查找、状态筛选和分页。首页展开“更多任务”查看历史任务，各岗位可查找本岗位全部任务。
- 保存后会显示保存时间、内容版本和修订号。长任务运行时可切换工作台，旧请求完成不会把页面拉回。

## 四个工作台

- **热点与竞品分析**。AIHOT v1 与 Hacker News 官方榜单每 30 分钟自动刷新。榜单采集、原文发布时间、讨论提交时间分别显示。刷新失败或仍在退避时保留上次成功的快照，并提示重试时间。「核对来源」可独立读取已接入的发布方正文，保存原文段落、链接和日期。标题页、社区评论和不可达页面会分别标明。同一原文和相同正文片段会标记可能共享的来源。证据随选题交接给文案台。GitHub Trending、Hugging Face Daily Papers 和 NewsNow 显示为候选。小红书竞品原帖可直接带入研究任务。
- **文案制作**。可接选题，也可导入旧稿。按内容任务保存正文、开头、拍摄单和提词器。交给剪辑前，必须记录来源事实、归因限定、示例真实性和文稿逻辑四项人工复核；改动正文后复核失效。视频交剪辑，文字和图文交发布与数据。
- **剪辑**。用本地路径添加原片或已有成片。现有口播区间裁剪、Whisper.cpp、FFmpeg 和 Chrome 本地字幕渲染通过版本化文件交接。口播默认 1.10×。剪后字幕与成片须人工审阅，报告提供开、中、尾抽帧与音轨检查。封面可用真实画面帧生成。模型和编解码依赖可通过 `GET /api/workbench/capabilities` 核对。
- **发布与数据分析**。预测与平台包绑定文件指纹和版本，明确授权后才可执行。独立的“仅保存预览”模式不建立正式预测，并隐藏发布授权与登记控件；需要发布时重新准备正式包。已提交待核实和已发布各有独立状态，作品以实际链接或 ID 登记。可导入后台快照，X 可主动启用经已有授权的 T+3 指标回收。复盘向 01 和 02 回流。图文、文字为手动发布登记路径。

四个工作台共享 `CONTENT-ID`。任务 Markdown、当前任务索引及发布与指标快照由本机工作区保存。侧栏「员工对话记录」用于查看本机已保存的员工聊天。

Hacker News 某条详情读取失败时，其余成功条目继续显示原榜单顺位，来源标为“部分更新”并列出缺口，不改写完整成功时间。全部失败才保留上次快照。明确过期缓存、日期冲突或无效日期的原文会保留供回查，但不能作为可引用证据触发自动出稿；发布日期未知的常青材料仍可分析，并明确不据此判为今日事件。本机模型改稿完整接收当前正文；上下文不足导致调用失败时保留原稿，不截去中段。

可选环境变量 `WORKBENCH_PROJECT_ROOT` 指定独立任务根目录。使用 `WORKBENCH_DATA_DIR` 时默认隔离任务记录和监控，可用 `WORKBENCH_ENABLE_MONITOR=1` 在隔离目录中启用真实只读监控。本机 OpenAI-compatible 代理为默认模型路线。可在独立入口启用 DeepSeek 官方 API。

如果本机已通过环境变量配置系统 HTTP(S) 代理，可使用 `NODE_USE_ENV_PROXY=1 npm start` 让受支持的 Node.js 版本遵守代理配置。保留 `NO_PROXY` 的回环地址（`localhost,127.0.0.1,::1`），让本机模型连接走本地。[Node.js 代理配置](https://nodejs.org/learn/http/enterprise-network-configuration)



## 第一次使用小红书研究

1. 在左侧点击“小红书内容研究”。
2. 点击“打开登录浏览器”。工作台会打开一个独立 Chrome 窗口。
3. 在该窗口中由你本人完成扫码登录和可能出现的安全验证。工作台不会读取或展示密码、Cookie、Token。
4. 回到工作台点击“检查登录状态”。状态显示“已连接”后即可搜索。
5. 输入主题和目标数量，点击“开始自动搜索”。每次最多 20 条。
6. 页面会显示找链接、逐条提取、成功数、失败数、当前链接和停止按钮。已完成结果写入本机 SQLite，重启后仍可查看。
7. 每张结果卡可以打开原帖、查看正文、图片文字、字幕、指标和提取方法，也可以重新提取或将可用文本存入共享知识库。

“清除专用登录”只删除 `data/xhs-browser-profile/`，不会影响其他 Chrome 用户目录。搜索与详情提取采用单任务、单页顺序处理、有限滚动，没有无限刷新或高并发。

## 内容提取层级

系统按下面的顺序处理帖子：

1. 网页结构化元数据和 JSON-LD。
2. DOM（文档对象模型）中的标题、作者、正文、标签、时间和可见指标。
3. Accessibility Tree（无障碍结构树）和页面可见文字兜底。
4. 图文正文不足时，对页面中可见的大图截图并运行本机 OCR（光学字符识别）。macOS 使用 Vision；其他系统可安装 Tesseract 与 `chi_sim` 中文模型。
5. 视频优先读取页面可见字幕或可访问字幕轨。只有存在用户有权处理的本地媒体时才允许调用本机 Whisper/Faster-Whisper；工作台不会绕过平台限制下载视频。
6. 本机模型已接通时，使用已有 OpenAI-compatible 代理清理重复界面文字；模型失败时保留原始提取结果。

页面结构变化、帖子删除、登录失效、验证码、平台限制、OCR/ASR 缺失都会以明确状态显示。失败诊断会记录失败阶段、最终 URL、页面标题、可见文本长度、定位器数量、登录/验证/平台限制判断和失败截图，不会把空结果显示成成功。

## 本机模型接入

在「本机模型设置」接入 OpenAI-compatible 代理。代理内部如有 OpenAI OAuth 登录，由代理自行处理。

在“模型设置”中填写：

1. 本机 API 根地址，例如 `http://127.0.0.1:端口/v1`，不要包含 `/chat/completions`。
2. 代理实际提供的模型标识。

保存后点击“测试本机代理”。只有测试成功，员工对话和小红书原文清洗才会请求该代理。本机代理连接配置不收集 API Key、Bearer Token 或 OAuth Token。

## DeepSeek 官方 API

1. 点击侧栏「DeepSeek 官方 API」，输入你在 DeepSeek 开放平台生成的 API Key，并点击「保存并同步」。
2. 从当前账户的官方 `GET /models` 目录选择可用于文本任务的模型，或选择跟随账户的默认选项。
3. 勾选「设为当前模型提供方」并保存。启用后，工作台的模型生成和员工对话调用 DeepSeek 官方 API。关闭后切回本机代理。小红书原文的后台清洗继续使用本机代理。
4. 打开设置、使用模型时会检查模型目录的新鲜度，也可以点击「刷新模型列表」。可用模型及权限由 DeepSeek 实时提供，新增模型无需修改工作台代码。

密钥由服务端保存到独立的本机权限文件，设置接口只返回状态和可用模型。启用 DeepSeek 时模型请求中的任务内容发送给 DeepSeek 官方 API。选择模型不触发发布。

## 数据位置

默认数据全部位于 `data/`：

- `db.json`：员工对话、共享知识库、发布数据。
- `model-connection.json`：不含凭据的本机代理地址、模型名和测试状态。
- `xhs-research.sqlite`：搜索任务、帖子、提取记录、任务关系和失败日志。
- `xhs-browser-profile/`：小红书专用 Chrome 登录状态。
- `xhs-artifacts/`：帖子截图、OCR 输入图和失败截图。

这些路径均已加入 `.gitignore`。可以用 `WORKBENCH_DATA_DIR=/另一个目录 npm start` 指定另一份隔离数据。

## 主要本机接口

- `GET /api/xhs/connection`：查看浏览器、OCR 和 ASR 状态。
- `POST /api/xhs/connection/open|check|clear`：打开、检查、清除专用登录环境。
- `POST /api/xhs/tasks`：创建关键词搜索任务。
- `GET /api/xhs/tasks`、`GET /api/xhs/tasks/:id`：查看历史和任务详情。
- `GET /api/xhs/posts?keyword=...&from=...&to=...`：按关键词或提取时间查询已保存帖子。
- `POST /api/xhs/tasks/:id/stop`：在安全节点停止任务。
- `POST /api/xhs/posts/:id/retry`：重新提取单帖。
- `POST /api/xhs/posts/:id/knowledge`：把已提取文本存入共享知识库。

完整技术结构见 [docs/小红书内容研究架构说明.md](docs/小红书内容研究架构说明.md)。

小红书页面会持续变化，且可能触发登录或安全验证。用户需遵守平台规则，只处理本人有权访问和使用的内容；遇到验证时由本人完成，系统不会规避平台限制。
